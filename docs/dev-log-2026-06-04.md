## 5. 이슈 및 해결

| 이슈 | 원인 | 해결 |
|---|---|---|
| 한글 PDF 텍스트 추출 깨짐 | `pdftoppm` 미설치 | `pdftotext -enc UTF-8` 대체 사용 |
| OG 이미지 한글 렌더링 실패 | node-canvas 한글 폰트 미지원 | Playwright 브라우저 렌더링으로 전환 |
| OG 이미지 경로 오류 | Git Bash `/c/` → `C:\c\` 오변환 | PowerShell에서 Windows 절대 경로로 직접 실행 |
| 카카오 공유 디버거 미작동 | PNG 394KB 용량 과다 + `/tool/debugger/sharing` 는 SDK 전용 도구 | JPEG 37KB 변환 + `/tool/debugger/og` 사용 안내 |
| 파티클 색상 하드코딩 | 테마 전환 시 violet 색상 고정 | `--clr-accent-rgb` CSS 변수 연동 |
